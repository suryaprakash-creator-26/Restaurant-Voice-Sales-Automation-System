# 🍽️ Restaurant Voice Sales Automation System

An AI-powered backend application built with Python and Flask that automates restaurant sales processing from WhatsApp voice messages.

## Tech Stack

* Python
* Flask
* SQLite
* Twilio WhatsApp API
* Google Speech Recognition
* HTML/CSS/JavaScript (Admin Dashboard)

## Architecture

WhatsApp Voice
        ↓
Speech Recognition
        ↓
Speech to Text
        ↓
Food Extraction
        ↓
SQLite Database
        ↓
Analytics Dashboard
